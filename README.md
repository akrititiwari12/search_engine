# 🤖 AI Chat with Groq

A simple AI chatbot built using **Streamlit**, **LangChain**, and **Groq Llama 3.3 70B**.

## 🚀 Features

- Interactive chat interface
- Powered by Groq Llama 3.3
- User enters their own API key
- Chat history
- Fast responses

## 🛠️ Technologies

- Python
- Streamlit
- LangChain
- LangChain-Groq
- python-dotenv

## 📦 Installation

Clone the repository:

```bash
git clone https://github.com/Ariti12/search_engine.git
```

Install dependencies:

```bash
pip install -r requirements.txt
```

Run the app:

```bash
streamlit run app.py
```
